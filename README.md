# Clement Telehealth — website concept

One-page site for Clement Telehealth: HRT, GLP-1 weight care, thyroid, men's health, hair and skin.

Open `index.html` in Chrome or Edge, or publish with GitHub Pages (Settings → Pages → Deploy from a branch → main / root).

## Notes
- Scroll-linked animations (GLP-1 spotlight, circle reveal) use CSS scroll-driven animations — full effect in Chrome/Edge.
- Placeholders to replace: prices, licensed states, FAQ answers, response times, safety information, contact details.
- Reviews are labeled samples — replace with real, verified member reviews before launch.
- Video: Mixkit stock (Mixkit License). Product photos were supplied for the concept; several show third-party brands/NDCs and a "research peptide" label — replace with Clement's own product imagery before launch.
